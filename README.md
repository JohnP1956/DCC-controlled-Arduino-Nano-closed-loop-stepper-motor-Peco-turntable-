This is my project to construct a OO gauge Peco turntable kit motorised with a Makerbase MKS42D closed loop stepper motor.  The construction details are in the RMweb link.  The user guide for the motor is attached as is the arduino code I developed to control the motor.  The code was developed using AI (Chat GPT, CoPilot and Claude) as I am not a coder.  I have also added a demo code for controling the turntable system with RR&CO Train Controller (Gold).
I recently noticed that MKS have updated their product to a serial commanded motor only.  However, the motor I used and its previous incarnation plus the kit to add a closed loop board to any NEMA 17 motor are still available on Aliexpress at the time of writing this README note (March 2025).
